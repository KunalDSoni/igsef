# Indo-Global Skills & Edu Foundation — Website Blueprint

Version: 1.0  
Prepared: 21 August 2026  
Status: Discovery and design handoff

This folder contains a complete implementation-planning blueprint for a public website for Indo-Global Skills & Edu Foundation. It is ready for estimation and structural Framer handoff, not production publication. It becomes build-ready when the P0 identity, content, ownership, legal/privacy, platform-feasibility, and exact-template-access blockers listed below are resolved. The recommended first release is a focused, credible institutional website that explains the foundation's intended areas of work, invites partnerships, and publishes verified corporate disclosures without inventing programmes, affiliations, or impact.

## Recommended MVP

Build six core pages first:

1. Home
2. About
3. Focus Areas
4. Partner With Us
5. Updates / Resources
6. Contact

Also include a Corporate Disclosures page and the necessary legal pages. Add programme detail pages, impact reporting, volunteering, grants, events, donations, or multilingual content only when the underlying operational and compliance processes exist.

## Reference design status

The supplied Framer project URL redirects to a Framer sign-in screen in the available browser session. The official Kidora marketplace listing and public demo were available, however, so the design specification maps the real template: photographic hero, ticker, rounded pastel cards, asymmetric editorial grids, programme and staff layouts, admissions, testimonials, pricing, blog CMS, forms, and responsive pages. The adaptation keeps that layout language while replacing its preschool positioning with a credible education-and-skills institution.

Before production design is locked, provide one of the following to verify whether the supplied copy differs from the public template:

- a public Framer preview URL;
- view access to the project in Framer; or
- full-page desktop and mobile screenshots.

This will allow a final component-by-component mapping without changing the requirements or content strategy.

## Definition of ready for build

The build can start when:

- the pages and MVP scope in `Requirement.md` are approved;
- the visual direction in `design.md` is approved;
- all P0 content inputs in `content.md` are supplied;
- the Framer reference is viewable or the documented adaptation is accepted;
- a single content approver and a single legal/compliance approver are named.
